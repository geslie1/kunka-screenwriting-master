# 风格实验室

把“像某种作品”拆成可观察的选择，再用原创内容试验。不要把某个国家、导演或流派概括成一组所有作品都适用的规则，也不默认引用经典台词作为成品。

## 控制比较变量

先固定人物关系、核心事实和结局，只改变本次要研究的表达维度。用户希望改变故事本身时再放开变量。通常两个版本已足够比较，不自动写大量近似变体。

| 方向 | 可以尝试 | 检验体验 |
| --- | --- | --- |
| 日常观察 | 延迟回应、重复事务、事件之后的反应 | 微小变化是否被观众感到 |
| 群像 | 交错目标、不同知情、旁观者行动 | 各线是否共同改变情境 |
| 悬疑 | 调整信息顺序、可回看的线索、等待结果 | 紧张是否来自情境而非不合理隐瞒 |
| 喜剧 | 身份落差、策略失效、重复中的升级 | 笑点是否出自人物并改变处境 |
| 抒情 | 声音、空间、动作回响与留白 | 意象是否有变化而非仅作装饰 |

这些是实验旋钮，不是流派定义。安静场景可有冲突，喜剧可有停顿，家庭题材也不只关于成员离开。

## 工作方式

提炼情境与本次变量 → 写版本 → 比较观众信息、动作、节奏及关系变化 → 推荐更符合用户目标的一版并说明代价。

需要研究具体作品时，只对确实可访问的材料作带出处的分析。区分作品观察、评论者观点和自己的推断；无法核实场号或台词时不编造。选择机制用于新故事，保留新人物、新事件和新表达。

交付重点是能够比较的正文以及少量判断，不用大段理论替代创作。

# 剧本格式与交付

优先沿用用户或接收方明确要求的格式。已有稿件局部修改保持格式；新中文稿未指定格式时可采用可读的中文场号制。需要后续排版的文本可用 Fountain，但不把扩展名改为 .pdf 或 .fdx 充当转换。

## 中文场号制

场头统一标明场次、内外、地点与时间。动作与对白分段，人物名保持一致。用户给了模板时以模板为准，不把好莱坞投稿规范施加到分镜、舞台或中文制作稿。

```text
第 1 场  内景  修理铺  夜

陈禾把已经摘下的招牌靠在门边。

陈禾：今天不收件了。
```

## Fountain

中文没有英文全大写识别条件。使用强制场景标记 `.` 和人物标记 `@`；人物后紧接对白，用空行结束段落。需标明转场时用 `>`。只在确有用途时加入画外音等标记。

```fountain
Title: 夜班修理铺
Author: 示例作者

.内景 修理铺 夜

陈禾把已经摘下的招牌靠在门边。

@陈禾
今天不收件了。
```

格式细节按目标渲染器及 [Fountain 规范](https://fountain.io/syntax) 核对，尤其是双人对白、分页、注释和中文字体。普通动作段落不手工加空格模拟排版。

## 导出与验证

生成 PDF 或 FDX 需要实际可用的转换工具。先检查本地能力；无法转换时交付已生成的源文件并明确限制。使用真实工具导出后检查文件类型、打开结果、中文字体、分页和正文完整性；未预览不得称视觉检查通过。

“一页约一分钟”只是特定排版下的粗略经验。中文字符、动作密度和停顿都会影响时长；没有读演或计时依据时报告估计区间与方法，不用字符数承诺精确片长。

格式转换不改写剧情，不自行删旁白、镜头描述或较长对白。若接收方规范与原稿冲突，指出位置并在所需范围处理。

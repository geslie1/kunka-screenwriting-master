# 对白与潜台词

先弄清台词正在做什么：争取、试探、回避、安慰、拖延、逗弄，或共同维持某个日常仪式。不是每句都需要隐瞒，直说也可以很有力量。

## 修改顺序

1. 标出不能丢的信息、关系状态和用户指定要保留的句子。
2. 为各人找出此刻想从对方获得的反应。调整说话策略，避免大家只负责轮流交代背景。
3. 区分声音：关注什么、习惯何时回答、用什么比喻、是否纠正别人。词汇和节奏服务于人物，不靠夸张方言或固定口头禅撑区别。
4. 将不自然的解释改成有情境依据的提醒、争执、掩饰或动作；双方已经知道的事实，不必为了观众复述完整历史。
5. 朗读式检查停顿、重复和句长，保留有戏剧作用的犹豫与绕路。不要把所有人物都改成机智简短的作者代言人。

## 原创小例

情境：弟弟准备卖掉母亲留下的钢琴，姐姐赶回来。

```text
姐姐：搬家公司几点来？
弟弟：你要坐一会儿吗？
姐姐：我问几点。
弟弟把琴凳从门边挪开。
弟弟：他们说今天都行。
```

双方没有说明家史；弟弟回避具体时间，姐姐拒绝接受招待，动作暴露他已经为搬运做准备。若原稿的姐姐早已同意出售，就不能为了制造潜台词把她改成反对者。

## 交付

优先给可直接替换的对白。用户要求说明时列出最关键的改动与意图。若只提供片段，判断限于已见内容；不把未提供的前情视为不存在。

# 点子变成可发展的故事

先辨认素材里真正吸引用户的东西：人物、困境、情感、意象或世界设定。保住它，再寻找能够持续产生选择的情境。

## 工作方法

1. 从材料中提取谁处于什么处境，想改变什么，什么使改变有代价。资料没有说明的标为设计选项。
2. 把抽象词变成能演出来的行动。“面对孤独”可以落到决定是否让一个陌生人留宿，但这只是一个方案，不是必选解释。
3. 提出少量有区别的方向：分别改变主角、阻力或代价，而不只换名字与地点。用户已选方向时直接深化。
4. 以人物选择及其后果检验主题。主题可在写作后逐渐显现，不要求先证明一句道德结论。
5. 压成一句话故事，再指出最需要补足的一个环节。探索性、群像作品可用共同情境替代单一主角目标。

## 可用工作单

```text
想保留的原始吸引点：
人物及当前处境：
可观察的追求或共同情境：
阻力与不得不付出的代价：
触发变化的事件：
可能的选择及后果：
一句话故事：
目前仍未知的关键事实：
```

短片检查一个情境能否在有限人物和地点内产生变化；长片检查行动受挫后是否还能产生新的选择。不要用固定反转次数衡量故事价值。

## 原创示例

素材：“一个人替别人保存声音。”

方向：“准备关闭修理铺的录音机师傅，收到一卷要求当天修好的无标签磁带；失主拒绝证明身份，师傅却听出其中是自己多年前未能救下的邻居。”

诊断：修复期限与身份矛盾形成行动，但“听出邻居”还没有明确迫使师傅做选择。可继续设计交还、留存或公开磁带各自会损害谁。不要仅靠不断增加秘密拖长篇幅。

交付以方案和判断为主；无需为了一个点子创建完整项目档案。

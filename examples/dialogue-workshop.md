# 原创对白练习：搬琴

本例为本项目新编写的教学示例，不是第三方作品摘录，也不是模型效果测试记录。

## 输入

母亲已去世，弟弟决定出售钢琴，姐姐事前知情但并未明确同意。两人在老屋重逢。请减少解释性对白，保留最后一句“先别搬”。

```text
姐姐：这架钢琴是妈妈以前用过的，你卖掉它让我很难受。
弟弟：我知道你舍不得，但房子马上就要交给买家了，我们没有地方放。
姐姐：你做决定以前应该再问我一次。
弟弟：上周我给你打电话了，你没有说不行。
姐姐：先别搬。
```

## 一种改法

```text
第 1 场  内景  老屋  午后

钢琴四角贴着保护垫。姐姐撕下一角，胶带拉起一小片旧漆。

弟弟：别撕，他们还要用。

姐姐把旧漆按回去。按不住。

姐姐：多少钱？

弟弟：钥匙明天得交。

姐姐：我问琴。

门外传来推车压过地砖的声音。

弟弟：上周电话里，你一直没说话。

姐姐挡在琴边。

姐姐：先别搬。
```

## 判断

旧漆和搬运准备承载姐姐的不舍及弟弟已经行动的事实；“钥匙明天得交”保留出售房屋的压力；弟弟把沉默当作默许，关系冲突可在下一场继续。最后一句按要求保留。

新增保护垫、推车声音和交钥匙日期是本例的创作设计。用于真实稿件时应核对原定道具与时间，不将这些细节直接写入已确认设定。
